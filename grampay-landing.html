01

What it actually does

Off-ramping crypto to Naira usually means leaving the conversation, opening an exchange, and manually walking through a withdrawal form. GramPay collapses that into a tool call an AI agent can make directly — the same connector pattern MoonPay's PayBox uses to let Claude and ChatGPT move money, applied to the specific problem of getting crypto into a Nigerian bank account.

01

Balance check

The agent reads your available crypto balance before proposing a cash-out amount.

02

Cash out to NGN

A single tool call initiates the transfer — crypto converted, Naira sent to a named bank account.

03

Status tracking

The agent (or you) can poll the transaction reference until it settles.

02

Connect it

GramPay runs as a remote MCP server over Streamable HTTP. Add it as a custom connector and the three tools below become available inside your conversation.

# Add as a custom connector
URL https://[your-deployment].up.railway.app/mcp
Auth Bearer <token>
Status: the connector endpoint is built and tested locally. Public deployment is the next step before this URL goes live — check the repo for current status.
check_balance Returns available balance across supported tokens, with a fiat equivalent.
cashout_to_ngn Initiates a crypto-to-Naira transfer to a named bank account.
check_transfer_status Looks up the current state of a transfer by its reference.

04

Roadmap

NOW

Solo operator, single provider

Live on IvoryPay. One user — the operator is also the fund owner.

NEXT

Public connector deployment

Streamable HTTP server deployed with token auth, addable as a real Claude connector.

THEN

Incorporation

Unlocks Breet and Quidax Ramp access, and lower fees at volume.

LATER

Multi-user, prepare/approve/execute

A confirmation step between the AI proposing a transfer and it actually executing.

05

Where things stand, plainly

Current limitations:
  • Validated in IvoryPay test mode end-to-end; live-key transactions are the next real-money milestone.
  • No multi-user support yet — there's no approval layer between an agent's request and execution.
  • Pre-incorporation, which is the reason Breet and Quidax aren't connected yet.
